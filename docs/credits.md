# Credits

Abacite's own code, its decimal engine and its app icon are covered by its [MIT license](../LICENSE). It is built on these projects:

- [Preact](https://preactjs.com) and [Preact Signals](https://github.com/preactjs/signals): the user interface. MIT license.
- [Electron](https://www.electronjs.org): the desktop app. MIT license.
- [Lucide](https://lucide.dev): the shapes of the icons in the status bar and session panel (settings, panel, chevron and close icons). ISC license.

The build and test tools (Vite, TypeScript, Vitest, Playwright, ESLint, Prettier, electron-builder) are listed in the `package.json` files and aren't part of the app.
