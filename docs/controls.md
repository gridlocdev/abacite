# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux) and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**, or **Help → Keyboard Shortcuts**). That window is built from the same list as the menus, so it is always up to date.

The expression line keeps the keyboard while no window is open: every key you type goes into it.

In a browser tab, **⌘N** and **⌘T** (**Ctrl+N**, **Ctrl+T**) belong to the browser, which opens a new window or tab. Use the command menu there for New Session, and the panel button at the right of the status bar for the session.

## Sessions

| Action                                         | macOS                    | Windows / Linux          |
| ---------------------------------------------- | ------------------------ | ------------------------ |
| New session                                    | **⌘N**                   | **Ctrl+N**               |
| Open another session                           | **File → Open Session…** | **File → Open Session…** |
| Keep sessions in another folder                | **⌘O**                   | **Ctrl+O**               |
| Rename, delete or export the session, or trash | **File** menu or **⌘K**  | **File** menu or **⌘K**  |

The session panel's header names the open session: click it to open another.

## Calculating

| Action                                          | macOS                   | Windows / Linux               |
| ----------------------------------------------- | ----------------------- | ----------------------------- |
| Calculate: put the line in the session          | **↩** or the **=** key  | **Enter** or the **=** key    |
| Repeat the last operation on the result         | **↩** on an empty line  | **Enter** on an empty line    |
| Clear the line, then the last result            | **⎋** or the **AC** key | **Esc** or the **AC** key     |
| Previous / next session line                    | **↑** / **↓**           | **Up** / **Down**             |
| Insert a session line's result / its expression | click / **⌥-click**     | click / **Alt-click**         |
| Copy, insert or delete a session line           | right-click the line    | right-click the line          |
| Copy the result                                 | **⇧⌘C**                 | **Ctrl+Shift+C**              |
| Paste, dropping grouping commas from numbers    | **⌘V**                  | **Ctrl+V**                    |
| Undo / redo typing, then session changes        | **⌘Z** / **⇧⌘Z**        | **Ctrl+Z** / **Ctrl+Shift+Z** |
| Clear the session                               | **⇧⌘⌫**                 | **Ctrl+Shift+Backspace**      |

| Scientific keypad                | **⌘2**                     | **Ctrl+2**                          |
| Classic entry on or off          | **⌘E**                     | **Ctrl+E**                          |
| Show or hide the session         | **⌘T** or the panel button | **Ctrl+T** or the panel button      |
| Switch degrees and radians       | **⇧⌘R** or the **Rad** key | **Ctrl+Shift+R** or the **Rad** key |
| System, Light or Dark appearance | **View** menu or Settings  | **View** menu or Settings           |
