# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux) and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**, or **Help → Keyboard Shortcuts**). That window is built from the same list as the menus, so it is always up to date.

The expression line keeps the keyboard while no window is open: every key you type goes into it.

In a browser tab, **⌘N** and **⌘T** (**Ctrl+N**, **Ctrl+T**) belong to the browser, which opens a new window or tab. Use the command menu there for New Tape and Show Tape.

## Tapes

| Action                                      | macOS                   | Windows / Linux         |
| ------------------------------------------- | ----------------------- | ----------------------- |
| New tape                                    | **⌘N**                  | **Ctrl+N**              |
| Open another tape                           | **File → Open Tape…**   | **File → Open Tape…**   |
| Keep tapes in another folder                | **⌘O**                  | **Ctrl+O**              |
| Rename, delete or export the tape, or trash | **File** menu or **⌘K** | **File** menu or **⌘K** |

The tape panel's header names the open tape: click it to open another.

## Calculating

| Action                                       | macOS                   | Windows / Linux               |
| -------------------------------------------- | ----------------------- | ----------------------------- |
| Calculate: put the line on the tape          | **↩** or the **=** key  | **Enter** or the **=** key    |
| Repeat the last operation on the result      | **↩** on an empty line  | **Enter** on an empty line    |
| Clear the line, then the last result         | **⎋** or the **AC** key | **Esc** or the **AC** key     |
| Previous / next tape line                    | **↑** / **↓**           | **Up** / **Down**             |
| Insert a tape line's result / its expression | click / **⌥-click**     | click / **Alt-click**         |
| Copy, insert or delete a tape line           | right-click the line    | right-click the line          |
| Copy the result                              | **⇧⌘C**                 | **Ctrl+Shift+C**              |
| Paste, dropping grouping commas from numbers | **⌘V**                  | **Ctrl+V**                    |
| Undo / redo typing, then tape changes        | **⌘Z** / **⇧⌘Z**        | **Ctrl+Z** / **Ctrl+Shift+Z** |
| Clear the tape                               | **⇧⌘⌫**                 | **Ctrl+Shift+Backspace**      |

| Show or hide the tape            | **⌘T**                     | **Ctrl+T**                          |
